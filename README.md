## How to run the examples

In every topic folder, the class named **`Driver`** has the `main` method. Run that file to see the example work.

If a topic has a few separate demos, I name them by what they do (like `OverridingDemo`).

To run from the terminal (you need the JDK installed):

```bash
javac Driver.java
java Driver
```

Or just open the folder in Eclipse / IntelliJ / VS Code and press Run.

**Java version:** I wrote the early programs to work with Java 8 syntax. Later topics (Spring Boot) use JDK 17 or newer. I'll note any version-specific code in the file itself.
